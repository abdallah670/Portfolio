# Plan: Fix CV Preview to Display in Browser Instead of Download

## Problem
When clicking "Preview online" button, the PDF downloads instead of displaying in browser.

## Analysis
Current implementation at `PortfolioController.cs:238-252`:
- Uses `PhysicalFile` to serve the PDF
- Sets `Content-Disposition: inline` header
- The issue may be that:
  1. The header is being set after the response is created
  2. The browser may not respect "inline" for PDFs
  3. Caching headers might interfere

## Solution

### Backend Fix (PortfolioController.cs)
1. Use `FileResult` with explicit `Content-Disposition: inline; filename=*.pdf`
2. Ensure no caching headers that might cause issues
3. Try serving directly from `wwwroot` folder which is already configured with `UseStaticFiles()`

### Alternative Approach
Create a dedicated endpoint for preview that serves from the static files path:
```csharp
[HttpGet("cv/preview")]
[AllowAnonymous]
public IActionResult GetCVPreview()
{
    return Redirect("/uploads/cv/Abdullah_Mohammed_CV.pdf");
}
```

### Frontend Fix (cv.component.ts)
1. Keep existing code (it already opens in new tab)
2. The issue is server-side

## Implementation Steps

1. **Option 1 - Backend**: Modify GetCV to use proper FileResult with Content-Disposition header set before returning
2. **Option 2 - Simpler**: Create a redirect endpoint that points to the static file URL which the browser can handle natively

Let me implement Option 2 as it's simpler and leverages the existing static file serving.
