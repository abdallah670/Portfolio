# PDF Preview Issue from Cloudinary - Resolution Plan

## Problem Analysis
The CV preview functionality is not displaying PDFs from Cloudinary properly. Based on the code review:

1. Frontend CV component calls `previewCV()` which opens `/api/portfolio/cv/preview`
2. Backend PortfolioController.PreCV() redirects to the CV URL stored in SystemSettings with key "cv_url"
3. The issue is likely related to:
   - Mixed content blocking (HTTP vs HTTPS)
   - CORS restrictions from Cloudinary
   - Missing Content-Disposition headers for inline PDF viewing
   - Cloudinary delivery settings

## Root Cause Investigation Needed
1. Check current CV URL stored in database (SystemSettings table)
2. Verify if the URL uses HTTPS
3. Check Cloudinary delivery settings for the PDF
4. Verify browser console for specific blocking errors

## Solution Approach
1. Ensure CV URL uses HTTPS
2. Add proper CORS headers if serving via proxy
3. OR modify preview endpoint to serve PDF directly with proper headers
4. OR use Cloudinary's HTML viewer for PDFs
5. OR add Content-Disposition: inline header for direct viewing

## Implementation Plan
1. [ ] Check current CV URL in database via admin panel or direct query
2. [ ] Verify URL protocol (HTTP vs HTTPS)
3. [ ] If HTTP, update to HTTPS in SystemSettings
4. [ ] Test direct Cloudinary URL in browser
5. [ ] If blocked, implement one of:
   - Proxy PDF through backend with proper headers
   - Use Cloudinary's PDF-to-image conversion for preview
   - Add iframe with proper sandbox attributes
   - Use Cloudinary's flexible auto-transformation for PDF viewing
