#### 1.1 Add Dashboard Stats API Endpoint (CRITICAL - BACKEND)
**Endpoint missing:** `GET /api/portfolio/dashboard-stats`

**Implementation:**
In `webapi/Portfolio.Api/Controllers/PortfolioController.cs`, add after line ~94 (after GetSkills):

```csharp
[HttpGet("dashboard-stats")]
[Authorize]
public async Task<IActionResult> GetDashboardStats()
{
    _logger.LogInformation("API: Getting dashboard stats");
    var stats = await _mediator.Send(new GetDashboardStatsQuery());
    return Ok(stats);
}
```

**Query Handler exists:** `GetDashboardStatsQueryHandler` (in Queries folder) returns `DashboardStatsDto` with:
- TotalProjects, DraftProjects, TotalMessages, UnreadMessages
- TotalSkills, SkillCategories, ProfileViews
- RecentProjects (list of anonymous objects)

**Frontend:** `ApiService.getDashboardStats()` already exists and expects `DashboardStats` interface.

#### 1.2 Fix Dashboard Component (FRONTEND)
**File:** `frontend/src/app/admin/pages/dashboard/dashboard.component.ts`

**Add missing method:**
```typescript
loadDashboardStats(): void {
  this.apiService.getDashboardStats().subscribe({
    next: (stats) => {
      this.stats = stats;
    },

      console.error('Failed to load dashboard stats:', err);
    }
  });
}
```

**Update ngOnInit** (currently lines 471-477) to include:
```typescript
ngOnInit(): void {
  this.loadDashboardStats();          // ADD THIS
  this.loadRecentProjects();
  this.loadSkillCategories();
  this.updateTime();
  setInterval(() => this.updateTime(), 1000);
}
```

**Note:** The `stats` property already declared (line 459). Skills chart creates after skillCategories load.

#### 1.3 Type Alignment Check
**Frontend DashboardStats interface:**
```typescript
export interface DashboardStats {
  totalProjects: number;
  draftProjects: number;
  totalMessages: number;
  unreadMessages: number;
  totalSkills: number;
  skillCategories: number;
  profileViews: number;
  recentProjects: Project[];  // <-- backend returns List<object>
}
```

**Backend DashboardStatsDto:**
- All numeric fields match ✓
- RecentProjects returns `List<object>` with anonymous types (Id, Title, Description, Stack, Status, Image) - this will work at runtime but TypeScript will complain about type mismatch. Since dashboard doesn't use `stats.recentProjects` (loads separate recentProjects), this is harmless. Could remove from interface or cast in API.

**Recommendation:** Keep as is OR change DashboardStats interface to:
```typescript
recentProjects: { id: number; title: string; description: string; stack: string; status: string; image: string }[];
```

But since unused, no action needed.
