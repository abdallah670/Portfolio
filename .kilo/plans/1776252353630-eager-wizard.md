# Admin Pages Implementation Plan

## Overview
Implement comprehensive admin pages for portfolio management with full backend CRUD operations.

---

## Priority Order (Based on User Selection)

1. **Dashboard** - Make dynamic with real data
2. **Projects** - Full CRUD with edit modal, image upload
3. **Journey** - Add as tab in Settings
4. **Skills** - Fix save issues
5. **UI Polish** - Toasts, loading states

---

## Phase 1: Dashboard Improvements (Priority: HIGH)

### Current State
- Dashboard shows metrics from API (page views, projects, messages, skills)
- Charts: Only static sparklines in metric cards
- Activities, Traffic Sources, Featured Project are hardcoded

### Improvements Needed

**Installation:**

- Line chart showing views over last 7 days
- Replace static sparklines in metric cards with actual line charts

**Chart Type 2: Traffic Sources (HIGH PRIORITY)**
- Donut/Pie chart
- Replace current progress bars with visual donut
- Segments: Organic Search, Social Media, Referral, Direct

**Chart Type 3: Skills Distribution (MEDIUM)**
- Bar chart per category
- Horizontal bars showing skill levels

**Implementation:**
```typescript

// Add chart configs
```

## Phase 2: Projects Full CRUD (Priority: HIGH)

### Current State
- List view with toggle publish, delete
- No create/edit functionality

### Add Project Create/Edit Modal
**Modal form fields:**
- Title (text) - required
- Year (text) - "2025"
- Category (select): Web Application, Full-Stack Platform, API, Mobile App
- Description (textarea)
- Stack (multi-select dropdown)
- Image (file upload)
- linkedinUrl (text)
- GithubUrl (text)  
- LiveUrl (text)
- Status (select): Production, Draft
- Color (select): emerald, cyan, pink, blue, purple
- IsFeatured (checkbox)
- DisplayOrder (number)

### Common Tech Stack for Dropdown
```typescript
stackOptions = [
  'C#', '.NET', '.NET 9', 'ASP.NET Core', 'Entity Framework',
  'SQL Server', 'Angular', 'Angular 17+', 'NgRx',
  'SignalR', 'Stripe', 'Hangfire', 'Git', 'REST API'
];
```

### API Methods (exist)
- `getAllProjectsAdmin()` - List all
- `createProject(project)` - Create
- `updateProject(project)` - Update  
- `deleteProject(id)` - Delete
- `uploadProjectImage(file)` - Upload image
